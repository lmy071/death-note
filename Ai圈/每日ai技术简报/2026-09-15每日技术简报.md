## 1. GitHub Copilot 自动模型选择新增三档：效率 / 平衡 / 智能

GitHub 9 月 14 日更新 Copilot Auto Model Selection，新增 **Efficiency、Balance、Intelligence** 三种策略。三档使用相同的可用模型池，但 Copilot 会逐 Prompt 判断任务，并按照用户选择的成本、质量与延迟偏好进行动态模型路由。功能正在 VS Code、Copilot CLI 与 GitHub Copilot App 中推出。

**为什么值得关注：** Coding Agent 的模型层正在从“手动 Model Picker”升级为真正的 **Policy-driven Model Router**。这意味着大型 TypeScript/Vue 仓库可以把简单文档、搜索和机械修改交给低成本模型，把复杂重构与 Debug 自动升级到强模型，而不需要开发者逐次切换。

**原始来源：** [GitHub Changelog — Configure cost and quality in Copilot auto model selection](https://github.blog/changelog/2026-09-14-configure-cost-and-quality-in-copilot-auto-model-selection/)

## 2. Salesforce Agentforce 推出长周期 Runtime：Agent 可持续工作数天到数周

Salesforce 9 月 14 日发布新一批 Job-ready Agents，并公布新的 **Long-horizon Runtime**。Agent 可以把目标拆成计划，在数天乃至数周持续执行；底层通过 Memory 保存跨 Session 上下文、Durable Execution 保持任务运行和恢复，并通过 Dynamic Steering 根据用户反馈调整行为。Multi-Agent Orchestration 也已 GA。

**为什么值得关注：** 企业 Agent 的基本执行模型正在从 `Request → Response` 转向 `Goal → Plan → Durable State → Continuous Execution → Human Steering`。这与后台 Coding Agent、持续 Issue 处理、长期项目维护等开发场景高度一致。

**原始来源：** [Salesforce — Agentforce job-ready agents and long-horizon runtime](https://www.salesforce.com/ap/news/press-releases/2026/09/14/ph-salesforce-expands-agentforce-with-a-new-portfolio-of-ai-agents-built-for-high-value-work/)

## 3. Perplexity 开始让 GPT-6 Astra 直接修改和监控端到端生产系统

OpenAI 9 月 14 日披露 Perplexity 的 Astra 使用案例：模型不仅编写代码，还会构造测试程序模拟外部 API/Connector 的真实响应，对应用进行端到端验证，并被用于修改真实软件系统和监控生产环境。Perplexity 表示，与前代模型相比，工程师可以显著减少人工检查频率。

**为什么值得关注：** Coding Agent 正跨过“生成代码”这一层，进入 `Implement → Simulate Dependencies → E2E Test → Modify System → Production Monitoring`。这意味着测试 Harness、Sandbox、权限边界、回滚和可观测性会成为 Agent 编程体验的一部分，而不是外围工具。

**原始来源：** [OpenAI — Perplexity trusts GPT-6 Astra with end-to-end systems](https://openai.com/index/perplexity-improving-accuracy-with-astra/)

## 4. Claude for Financial Advisors 发布：MCP Connector + Skills 开始成为垂直 Agent 产品模板

Anthropic 9 月 14 日推出 Claude for Financial Advisors，把面向金融顾问的 Workflow Skills 与数据 Connector 打包到一个产品中，可连接 Charles Schwab、BlackRock、Addepar、Envestnet、iCapital、Orion 等系统，用于研究、会前准备、组合分析和后续文档工作。合作伙伴 Orion 同日公布了基于 MCP 的实时投资组合与 CRM Connector。

**为什么值得关注：** 垂直 Agent 产品正在形成非常清晰的工程模板：`Frontier Model + Domain Skills + MCP Connectors + Live Enterprise Data + Existing Permissions + Human Judgment`。这比单纯针对行业微调一个模型更容易持续迭代，也进一步提升 MCP 作为 Agent 数据/工具协议层的重要性。

**原始来源：** [Reuters — Anthropic targets financial advisers with new Claude tool](https://www.reuters.com/business/anthropic-targets-financial-advisers-with-new-claude-tool-2026-09-14/) · [Orion — MCP connector for Claude for Financial Advisors](https://www.businesswire.com/news/home/20260914255610/en/Orion-Expands-Anthropic-Collaboration-as-Launch-Partner-for-Claude-for-Financial-Advisors)

## 5. Vue/Vite 前端生态更新：@vitejs/plugin-vue 6.0.9 与 Turborepo 2.10.13 同日发布

9 月 14 日前端工具链也有新版本活动：官方 Vue SFC Vite 插件 `@vitejs/plugin-vue` 发布 6.0.9；Turborepo 发布 2.10.13 stable。前者是 Vue SFC → Vite 编译链的核心插件，后者则是大型 JavaScript/TypeScript Monorepo 常用的 Rust 构建系统。

**为什么值得关注：** 对 Vue + TypeScript 项目，这两条更新比泛化 AI 新闻更值得实际检查依赖。特别是在 Coding Agent 高频运行 Build/Test/Lint 的工作流下，Vite Plugin 与 Monorepo 构建系统已经成为 Agent 吞吐量的直接组成部分。升级前建议先在 CI 中验证 HMR、SFC 编译、缓存命中和 workspace task graph。

**原始来源：** [vitejs/vite-plugin-vue 官方仓库](https://github.com/vitejs/vite-plugin-vue) · [vercel/turborepo 官方 Releases](https://github.com/vercel/turborepo/releases)
