## 1. GitHub Copilot：MCP、Skills、Plugins 统一进入 Customize 中心

GitHub 将 MCP Servers、Agent Plugins、Skills、Canvases 整合进 Copilot App 的 Customize 页面，方便发现、安装和组合 Agent 扩展能力。

**为什么值得关注：** Agent 扩展生态开始从“协议和格式”进入“分发和治理”阶段。团队未来可以把内部 Vue 规范、设计系统 Skill、Jira / GitHub MCP 等能力统一分发给 Coding Agent。

**原始来源：** [GitHub Changelog — Copilot Customize](https://github.blog/changelog/)

## 2. TypeScript 6.0：为原生 TypeScript 7 做迁移准备

TypeScript 6.0 是重要的过渡版本，新增 `es2025`、Temporal 等类型支持，同时弃用部分旧模块解析和配置行为，例如 `moduleResolution: node/node10`、`baseUrl` 等。

**为什么值得关注：** 对 `Vue 3 + Vite + TypeScript` 项目，建议优先检查 `compilerOptions.types`、`moduleResolution`、`baseUrl / paths`、`lib` 和 `esModuleInterop`。这会直接影响后续升级 TypeScript 7 的成本。

**原始来源：** [TypeScript 6.0 Release Notes](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-6-0.html)

## 3. OpenAI Jalapeño：自研推理芯片面向 Agent 低延迟场景

OpenAI 公布第一代自研 inference chip Jalapeño 的实测结果，重点面向高交互、大量连续推理步骤的 Agent workload。

**为什么值得关注：** Agent 一次任务通常会执行大量“推理 → 工具调用 → 测试 → 修复”循环，因此单步延迟、吞吐和功耗会直接决定最终体验和成本。模型竞争正在扩展到推理基础设施层。

**原始来源：** [OpenAI](https://openai.com/)

## 4. ChatGPT Work：Scheduled Tasks 支持事件触发

Scheduled Tasks 开始支持由 Gmail、Slack、GitHub Pull Request 等外部事件触发，而不仅是固定时间轮询。

**为什么值得关注：** Agent 工作流正在转向事件驱动架构：`Event → Context → Agent → Tool → Action`。这更适合 PR Review、CI Failure 调查、Slack Bug 自动建 Issue 等软件工程场景。

**原始来源：** [OpenAI ChatGPT Release Notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)

## 5. Vercel AI Gateway：MiniMax M3 / M2.7 可直接连接 Coding Agent

Vercel AI Gateway 增加 MiniMax 模型，并支持通过 CLI 将 Gateway 接入 Claude Code、Codex、OpenCode、Cursor、Pi 等 Coding Agent，同时支持 Provider Ordering 与 Failover。

**为什么值得关注：** Coding Agent 正出现越来越清晰的 Model Abstraction Layer。团队可以按照代码能力、Token 成本、延迟和可用性动态切换模型，而不是把整个工程链路绑定到单一厂商。

**原始来源：** [Vercel Changelog](https://vercel.com/changelog)

## 今日结论

如果只看两条，优先看 **TypeScript 6.0** 和 **GitHub Copilot Customize**。

- TypeScript 6.0 对现有 Vue / Vite / TS 工程有直接迁移价值。
