# Vue2 50个核心知识点

## 一、基础概念（1-6）

### 1. Vue 的优点和缺点

- **优点：渐进式、组件化开发、虚拟 DOM、响应式数据、单页面路由、数据与视图分离**
- 缺点：单页面不利于 SEO、不支持 IE8 以下、首屏加载时间相对较长

### 2. 为什么说 Vue 是一个渐进式框架？

渐进式框架含义：不强制你一次性接受并使用全部功能特性。你想用 Router 就用，不想用 Vuex 就可以不用，按需选择，自由组合。

### 3. Vue 和 React 的异同点

**相同点：都使用虚拟 DOM、都支持组件化开发、都是单向数据流、都支持服务端渲染（SSR）**

不同点：React 使用 JSX，Vue 使用 template；React 数据变化需手动 setState，Vue 自动响应（Object.defineProperty）；React 单向绑定，Vue 支持双向绑定；React 用 Redux/MobX，Vue 用 Vuex。

### 4. MVVM 是什么？和 MVC 有何区别？

MVC：Model（从数据库取数据）→ Controller（用户交互）→ View（展示数据），Controller 将 Model 数据展示在 View 上。

MVVM：ViewModel 做了两件事——① 将 Model 转化成 View（数据绑定）；② 将 View 转化成 Model（DOM 事件监听）。实现了 View 和 Model 自动同步，数据变更时视图自动更新。

区别：MVVM 比 MVC 精简，简化了业务与界面依赖，解决了数据频繁更新问题，不需要手动操作 DOM 元素。注意：Vue 不是严格符合 MVVM，因为可以用 ref 让 Model 和 View 直接通信。

### 5. Vue 和 jQuery 的区别？为什么放弃 jQuery 用 Vue？

- jQuery 直接操作 DOM；Vue 不直接操作 DOM，只需操作数据，视图自动更新
- 频繁操作 DOM 时，jQuery 性能较低；Vue 使用虚拟 DOM，大大提高更新性能
- Vue 集成了 Router、Vuex 等工具，开发效率更高

## 二、组件与 Props（7-12）

### 7. 为什么 data 是一个函数且返回一个对象？

防止组件被多处复用时，多个实例之间共享同一个 data 对象，造成数据互相污染。每次调用组件时，data 函数都返回一个全新的对象。

### 8. 组件之间的传值方式有哪些？

- 父传子：props 接收
- 子传父：$emit + 事件
- $parent / $children 获取实例通信
- $attrs / $listeners（二次封装组件时传值）
- $refs 获取组件实例
- Vuex 状态管理
- eventBus 跨组件触发事件
- provide / inject（官方不建议用在正式生产环境）
- localStorage / sessionStorage
- 路由传值

### 9. Props 怎么自定义验证？

```jsx
props: {
  num: {
    default: 1,
    validator: function (value) {
      // 返回 false 则验证不通过，Vue 会报警告
      return [1, 2, 3, 4, 5].indexOf(value) !== -1
    }
  }
}
```

### 10. 如果子组件改变 props 里的数据会发生什么？

- 修改基本类型 props：Vue 会报错（Avoid mutating a prop directly）
- 修改引用类型 props 的属性（如 obj.key = value）：不报错，且父组件数据会同步变更（但不推荐这样做）
- 直接修改整个引用类型 props（如 this.obj = xxx）：会报错

### 11. 路由有哪些模式？各有什么不同？

- **hash 模式：通过 URL 中 # 号后内容的更改触发 hashchange 事件实现路由切换，兼容性好，不需要服务器配置**
- history 模式：基于 HTML5 的 pushState / replaceState 切换 URL，需要服务器端配置 fallback（所有路径返回 index.html），否则刷新 404
- abstract 模式：适用于非浏览器环境（如 Node.js、Weex），不依赖 window 对象

### 12. 路由的钩子函数有哪些？

全局钩子：beforeEach（跳转前，接收 to / from / next）、afterEach（跳转后）

路由独享钩子：beforeEnter（在路由配置中定义）

组件内路由钩子：beforeRouteEnter（进入组件前）、beforeRouteUpdate（路由复用组件时）、beforeRouteLeave（离开组件时）

## 三、模板与指令（13-25）

### 13. 使用过哪些 Vue 的内部指令？

- v-text：设置元素的 textContent
- v-html：设置元素的 innerHTML（注意 XSS 风险）
- v-show：通过 CSS display 控制显隐，适用于频繁切换
- v-if / v-else / v-else-if：通过 DOM 增删控制显隐，适用于偶尔切换
- v-for：循环渲染列表，必须配合 key 使用
- v-on（@）：绑定事件
- v-bind（:）：绑定属性
- v-model：双向绑定（表单元素）
- v-slot（#）：插槽
- v-once：只渲染一次，后续跳过
- v-pre：跳过该元素及其子元素的编译
- v-cloak：隐藏未编译完成的双括号，编译完成后自动移除

### 14. 使用过哪些 Vue 的修饰符？

- 表单修饰符：.lazy（失焦才更新 v-model）、.trim（去除首尾空格）、.number（转数字）
- 事件修饰符：.stop（阻止冒泡）、.prevent（阻止默认行为）、.capture（捕获模式）、.self（只在自身触发）、.once（只触发一次）、.passive（提升滚动性能）
- 按键修饰符：.enter、.tab、.delete、.esc、.space、.up、.down、.left、.right
- 鼠标修饰符：.left、.middle、.right
- 其他：.native（在自定义组件上绑定原生事件）、.sync（简化子组件修改父组件值的语法）

### 15. 如何设置动态 class 和动态 style？

```html
<!-- 动态 class：对象语法 -->
<div :class="{ 'is-active': isActive, 'red': isRed }"></div>

<!-- 动态 class：数组语法 -->
<div :class="['is-active', isRed ? 'red' : '']"></div>

<!-- 动态 style：对象语法 -->
<div :style="{ color: textColor, fontSize: '18px' }"></div>
```

### 16. v-if 和 v-show 有何区别？

- v-if：通过 DOM 增删控制显隐，切换时会触发组件的生命周期（创建/销毁），适用于切换频率低的场景
- v-show：通过 CSS display:none 控制显隐，不会触发组件生命周期，适用于频繁切换的场景

### 17. 为什么 v-if 和 v-for 不建议用在同一标签？

在 Vue2 中，v-for 优先级高于 v-if。同一标签使用时，会先遍历所有元素，再逐个判断 v-if 条件，造成大量无用渲染。正确做法：用 computed 过滤列表后再 v-for，或在外层用 template + v-if 包裹。

### 18. 为什么不建议用 index 做 key？为什么不建议用随机数做 key？

用 index 做 key：列表头部插入元素时，所有已有元素的 index 都会变化，导致 Vue 重新渲染所有节点，性能差，还可能出现状态错乱。

用随机数做 key：每次渲染 key 都不同，Vue 会认为所有节点都是新的，全部重建，性能极差。正确做法：使用数据唯一标识（如 id）作为 key。

### 19. 动态指令和动态参数如何使用？

```html
<template>
  <!-- 动态事件名 -->
  <aButton @[someEvent]="handleClick()" />

  <!-- 动态 prop 名 -->
  <aButton :[someProp]="1000" />
</template>

<script>
export default {
  data() {
    return {
      someEvent: condition ? 'click' : 'dblclick',
      someProp: condition ? 'num' : 'price'
    }
  }
}
</script>
```

## 四、响应式原理（26-35）

### 20. Vue2 响应式是怎么实现的？

整体思路：数据劫持 + 发布订阅模式（观察者模式）。

1. 对象：通过 Object.defineProperty 递归劫持每个属性的 getter/setter，getter 做依赖收集（dep.depend），setter 触发派发更新（dep.notify）
2. 数组：出于性能考虑，没有对数组下标进行劫持，而是重写了数组原型上的 7 个方法（push/pop/shift/unshift/splice/sort/reverse），在方法调用时自动触发更新
3. 依赖追踪：每个响应式属性有独立的 dep，存放它所依赖的 watcher；属性变化时通过 dep.notify 通知所有 watcher 更新

### 21. 为什么只对对象进行劫持，而要对数组进行方法重写？

对象通常只有几十个属性，逐个劫持性能开销可接受。数组可能有成百上千项，如果对每个下标都进行 Object.defineProperty 劫持，性能消耗极大。因此 Vue 选择重写数组原型方法，在方法调用时统一触发更新，是性能和功能之间的最优平衡。

### 22. 对象新属性无法更新视图？删除属性也无法更新视图？为什么？怎么办？

原因：Object.defineProperty 只能在对象已有属性上劫持，新增属性和删除属性无法被检测到。

解决：新增属性用 Vue.set(target, key, value) / this.$set；删除属性用 Vue.delete(target, key) / this.$delete。

### 23. 直接 arr[index] = xxx 无法更新视图？为什么？怎么办？

原因：Vue 没有对数组下标进行 Object.defineProperty 劫持（原因同上，性能考虑）。

解决：使用 arr.splice(index, 1, value) 或 Vue.set(arr, index, value)。

### 24. Vue.set 方法的原理？

```jsx
function set(target, key, val) {
  // 数组情况：调用 splice 触发响应式更新
  if (Array.isArray(target)) {
    target.length = Math.max(target.length, key)
    target.splice(key, 1, val)
    return val
  }

  const ob = target.__ob__

  // 对象已有属性：直接赋值（已响应式处理）
  if (key in target && !(key in target.__proto__)) {
    target[key] = val
    return val
  }

  // 新增属性：手动进行响应式处理
  defineReactive(target, key, val)
  ob.dep.notify()  // 通知更新
  return val
}
```

### 25. Vue.delete 方法的原理？

```jsx
function del(target, key) {
  // 数组情况：调用 splice 触发响应式更新
  if (Array.isArray(target)) {
    target.splice(key, 1)
    return
  }

  const ob = target.__ob__

  // 属性不存在，直接返回
  if (!(key in target)) return

  // 删除属性
  delete target[key]

  // 通知更新
  if (ob) ob.dep.notify()
}
```

### 26. 不需要响应式的数据应该怎么处理？

两种处理方式：

- 方法一：定义在 data 的 return 之外，直接挂载到 this 上（如 this.list = xxx），不会走响应式处理
- 方法二：使用 Object.freeze() 冻结对象，Vue 不会对其做响应式处理，适合大量静态数据（如下拉框选项、常量配置）

### 27. Vue 的模板编译原理？

三个阶段：

- 解析（Parse）：将 template 模板字符串解析成 AST（抽象语法树）
- 优化（Optimize）：遍历 AST，标记静态节点（static node），后续更新时跳过这些节点，提升性能
- 生成（Generate）：将优化后的 AST 转换成 render 函数字符串，最终编译成可执行的 render 函数

### 28. Vue 的模板编译原理？

第一阶段：解析（Parse）— 将 template 字符串解析成 AST（抽象语法树）

第二阶段：优化（Optimize）— 遍历 AST，标记静态节点，后续 patch 时跳过，提升性能

第三阶段：代码生成（Generate）— 将 AST 转换成 render 函数字符串

## 五、computed 与 watch（29-34）

### 29. computed 和 watch 有何区别？

- computed：依赖多个变量计算出一个变量（多对一），具有缓存机制，依赖不变则复用结果，不能进行异步操作
- watch：监听一个变量变化，执行回调（一对多），可进行异步操作

### 30. watch 有哪些属性，分别有什么用？

- handler：监听变化时执行的回调函数
- immediate：设为 true 时，组件创建后立即执行一次 handler
- deep：设为 true 时，深度监听对象内部变化（性能消耗较大，慎用）

### 31. 计算变量时，methods 和 computed 哪个好？

computed 更好。computed 有缓存机制，依赖值不变时会直接复用缓存结果；methods 每次调用都会重新执行计算。在模板中多次使用同一个计算值时，computed 只计算一次，methods 会计算多次。

### 32. watch 监听一个对象时，如何排除某些属性的监听？

```jsx
mounted() {
  Object.keys(this.params)
    .filter(key => !['c', 'd'].includes(key))
    .forEach(key => {
      this.$watch(
        (vm) => vm.params[key],
        handler,
        { deep: true }
      )
    })
}
```

### 33. computed 和 watch 的原理？

computed 本质是一个惰性 watcher，通过 dirty 标志位控制是否重新计算。首次访问时 dirty=true 触发计算，计算后缓存结果并将 dirty 置为 false。当依赖的响应式数据变化时，dirty 重新置为 true，下次访问时才重新计算（惰性求值）。

watch 本质是 user watcher，在组件初始化时对 expOrFn 求值收集依赖，当依赖变化时立即执行回调（可配置 immediate 在初始化时也执行一次）。

## 六、生命周期（34-37）

### 34. Vue 的生命周期有哪些？

- beforeCreate：实例刚初始化，data/methods 均未初始化，无法访问数据和事件
- created：data/methods 已初始化，可访问数据，但 DOM 未挂载，$el 不可用
- beforeMount：虚拟 DOM 已生成，但尚未转为真实 DOM 挂载到页面
- mounted：真实 DOM 已挂载完成，可操作 DOM、发起网络请求
- beforeUpdate：数据更新后，新虚拟 DOM 已生成，但尚未 patch 到真实 DOM
- updated：新旧虚拟 DOM 已 diff 并 patch，真实 DOM 更新完成
- beforeDestroy：实例销毁前，仍可访问数据，适合清理定时器、解绑事件
- destroyed：实例已销毁，子实例销毁、指令解绑、事件解绑
- activated / deactivated：keep-alive 缓存组件的激活/停用钩子
- errorCaptured：捕获子孙组件错误，返回 false 可阻止错误继续向上传播

### 35. 父子组件生命周期执行顺序

**加载渲染过程：父 beforeCreate → 父 created → 父 beforeMount → 子 beforeCreate → 子 created → 子 beforeMount → 子 mounted → 父 mounted**

更新过程：父 beforeUpdate → 子 beforeUpdate → 子 updated → 父 updated

销毁过程：父 beforeDestroy → 子 beforeDestroy → 子 destroyed → 父 destroyed

### 36. Vue 的 hook 事件怎么使用？

同一组件：使用 this.$once('hook:beforeDestroy', callback) 监听生命周期事件，避免在 data 中定义额外的 timer 变量。

父子组件：父组件可使用 @hook:mounted="handleChildMounted" 监听子组件的生命周期，不需要子组件手动 $emit。

## 七、nextTick 与异步更新（37-39）

### 37. nextTick 的用处和原理？

**用处：Vue 采用异步更新策略，同一事件循环内多次修改数据只会触发一次视图更新。因此数据修改后无法立即获取最新 DOM，需要使用 this.$nextTick() 在 DOM 更新完成后执行回调。**

原理：维护一个 callbacks 数组，每次调用 nextTick 时将回调压入数组。异步执行采用优雅降级策略：Promise → MutationObserver → setImmediate → setTimeout。优先使用微任务，避免多一次 UI 渲染队列，节省性能。

### 38. 为什么 nextTick 优先是微任务？

优先使用 Promise.then（微任务），这样可以在同一个事件循环中执行回调，避免多一个宏任务队列，减少一次不必要的 UI 渲染，节省性能。

## 八、Diff 算法与虚拟 DOM（39-42）

### 39. 虚拟 DOM 是什么？

虚拟 DOM 是一个 JavaScript 对象，是真实 DOM 的描述对象。每次数据更新时，Vue 会生成新的虚拟 DOM 树，与旧虚拟 DOM 树进行对比（diff），计算出最小变更量，然后只更新变化的部分到真实 DOM 上，减少直接操作 DOM 的性能开销。

### 40. Diff 算法的核心流程？

- 调用 patch 方法，传入新旧虚拟 DOM，开始同层对比
- 调用 isSameNode 方法，对比新旧节点是否同类型节点（sameVnode 判断 key + tag + 注释 + data）
- 如果不同，新节点直接替换旧节点
- 如果相同，调用 patchVnode 进行更深层对比：纯文本节点直接替换文本；旧有子节点新没有则删除；旧没有新有则新增；都有子节点则调用 updateChildren 做 diff
- updateChildren 使用首尾指针对比法（双端 diff），新旧节点列表各两个指针从头尾同时对比，减少移动次数

### 41. key 的作用是什么？

key 是 Vue 中虚拟 DOM 节点的唯一标识。在 diff 过程中，sameVnode 函数通过 key 判断两个节点是否相同。使用稳定的 key（如 id），Vue 能精确识别哪些节点可以复用，从而最小化 DOM 操作。使用 index 或随机数作为 key 会导致不必要的节点复用和重建。

## 九、Vuex 状态管理（42-43）

### 42. Vuex 有哪些属性？用处是什么？

- State：定义应用状态的数据结构，存放默认初始状态
- Getter：允许组件从 Store 中获取数据（类似 computed），mapGetters 将 getter 映射到局部计算属性
- Mutation：唯一更改 Store 状态的方法，必须是同步函数
- Action：用于提交 Mutation（而不是直接变更状态），可以包含异步操作
- Module：允许将单一 Store 拆分为多个模块，同时保存在单一状态树中

## 十、SSR 服务端渲染（44）

### 43. Vue 的 SSR 是什么？有什么好处？

**SSR（Server Side Render）即服务端渲染，在 Node.js 服务端将组件渲染成 HTML 字符串返回给浏览器，浏览器再进行「激活」（hydration）使之成为可交互页面。**

- 好处一：首屏加载更快（服务端直接返回完整 HTML）
- 好处二：更好的 SEO（爬虫可直接看到完整页面内容）

## 十一、插槽与自定义指令（45-47）

### 44. 插槽的使用及原理？

- 普通插槽：编译时会被解析成 _t 函数，接收插槽名称参数（默认 'default'），执行后渲染对应内容
- 作用域插槽：编译时被封装成函数放在 scopedSlots 对象中，_t 第二个参数接收子组件传递的数据

### 45. 自定义指令的钩子函数？

- bind：指令绑定到元素时调用（只调用一次）
- inserted：绑定元素插入父节点时调用
- update：所在组件 VNode 更新时调用
- componentUpdated：所在组件及其子组件 VNode 全部更新后调用
- unbind：指令与元素解绑时调用（只调用一次）

### 46. 自定义 v-model？

```jsx
export default {
  model: {
    event: 'change',   // 自定义事件名
    prop: 'checked'     // 自定义 prop 名
  },
  props: {
    checked: Boolean
  },
  methods: {
    handleChange(e) {
      this.$emit('change', e.target.checked)
    }
  }
}
```

## 十二、杂项高频考点（47-50）

### 47. provide 和 inject 是响应式的吗？

- **引用类型（对象/数组）：可以实现响应式，因为传递的是引用**
- 基本类型（字符串/数字）：不能实现响应式，因为传递的是值的副本

### 48. Vue 的 el 属性和 $mount 优先级？

同时存在时，el 优先级 > $mount。如果 el 指定了挂载点，$mount 会被忽略。

### 49. 相同的路由组件如何重新渲染？

多个路由解析为同一个 Vue 组件时，Vue 默认出于性能考虑不会重新渲染。解决方法：给 <router-view> 添加 :key="$route.path"，让路径变化时强制重建组件。

### 50. 审查元素时发现 data-v-xxxxx，这是什么？

这是 Vue 中 scoped 样式模块化的效果。当 <style> 标签添加 scoped 属性时，Vue 会为当前组件的所有 DOM 元素添加一个唯一的 data-v-xxx 属性，然后通过属性选择器实现样式隔离，确保各组件的 CSS 互不影响。

### 51. 如何获取 data 中某个数据的初始状态？

```jsx
this.formData = this.$options.data().formData
```

### 52. router.push、router.replace、router.go 的区别？

- router.push：跳转页面，向 history 栈添加记录，支持后退
- router.replace：跳转页面，不向 history 栈添加记录，替换当前记录，不支持后退到前一页
- router.go(n)：正数前进 n 页，负数后退 n 页
