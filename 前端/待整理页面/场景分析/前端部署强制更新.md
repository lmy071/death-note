# 前端部署强制更新

在前端项目迭代部署后，用户浏览器通常会缓存旧的静态资源（JS/CSS/HTML），导致无法立即看到最新功能。本文提供**4 种通用、低成本、高可用**的强制更新方案，覆盖 Vue/React/ 原生 HTML 等所有前端项目，可直接落地使用。

## 方案一：HTML 禁用缓存（最简单，推荐基础项目使用）

直接在入口 `index.html` 添加**禁用缓存的 meta 标签**，让浏览器每次都请求最新的 HTML 文件，从根源避免缓存。

### 使用方法

在 `public/index.html` 的 `<head>` 顶部添加：

```jsx
<!-- 强制浏览器不缓存 HTML，每次请求最新版本 -->
<meta http-equiv="Cache-Control" content="no-cache, no-store, must-revalidate">
<meta http-equiv="Pragma" content="no-cache">
<meta http-equiv="Expires" content="0">
```

### 原理

- `no-cache`：不使用本地缓存，必须向服务器验证资源
- `no-store`：完全不存储缓存文件
- `Expires: 0`：立即过期

### 适用场景

小型项目、简单静态页面、不想改动业务代码的场景

## 方案二：构建文件加版本哈希（工程化标准方案）

**Vue/React 项目默认自带**，无需手动配置，构建时自动给 JS/CSS 文件添加哈希后缀，文件内容变化 → 哈希值变化 → 浏览器自动加载新文件。

### 效果示例

```jsx
# 旧文件
app.abc123.js
# 新部署后
app.def456.js
```

### 配置确认（Vue 为例）

`vue.config.js` 保持默认配置即可，无需修改：

```jsx
module.exports = {
  filenameHashing: true, // 默认开启，生成带哈希的文件名
};
```

### 优势

- 无需业务代码入侵
- 浏览器自动识别，无兼容性问题
- 静态资源缓存最优（内容不变，哈希不变，缓存生效）

## 方案三：版本号校验 + 强制刷新（最通用，推荐中大型项目）

核心思路：**前端维护版本号 → 部署时更新版本号 → 页面轮询对比 → 不一致则强制刷新**。

### 步骤 1：创建版本配置文件

在 `public` 目录新建 `version.json`：

```jsx
{
  "version": "1.0.0"
}
```

### 步骤 2：封装版本检查工具函数

新建 `src/utils/versionUpdate.js`：

```jsx
/**
 * 版本检查：对比本地缓存版本和服务器最新版本
 */
export async function checkVersionUpdate() {
  try {
    // 1. 请求服务器上的最新版本号（禁用缓存）
    const response = await fetch(`/version.json?t=${Date.now()}`, {
      headers: { "Cache-Control": "no-cache" },
    });
    const { version: serverVersion } = await response.json();

    // 2. 获取本地缓存的版本号
    const localVersion = localStorage.getItem("APP_VERSION");

    // 3. 首次访问：保存版本号，不刷新
    if (!localVersion) {
      localStorage.setItem("APP_VERSION", serverVersion);
      return;
    }

    // 4. 版本不一致：强制刷新，并更新本地版本
    if (serverVersion !== localVersion) {
      localStorage.setItem("APP_VERSION", serverVersion);
      // 强制刷新（跳过缓存）
      window.location.reload(true);
    }
  } catch (error) {
    console.log("版本检查失败", error);
  }
}

/**
 * 轮询检查版本（可配置间隔时间）
 */
export function startVersionCheckTimer(interval = 5 * 60 * 1000) {
  // 立即执行一次
  checkVersionUpdate();
  // 定时轮询
  setInterval(checkVersionUpdate, interval);
}
```

### 步骤 3：在项目入口全局调用

`src/main.js`（Vue）/ `src/index.js`（React）：

```jsx
import { startVersionCheckTimer } from "@/utils/versionUpdate";

// 启动版本检查（默认5分钟检查一次）
startVersionCheckTimer();
```

### 步骤 4：部署时更新版本

每次发布新版本，**只需要修改 `version.json` 里的版本号**即可触发全量用户强制更新。

### 优势

- 精准控制更新时机
- 无侵入、低性能消耗
- 支持所有前端框架

## 方案四：Service Worker 主动更新（PWA 项目专用）

如果项目使用 PWA（Service Worker），可通过 SW 监听资源更新，自动触发刷新。

### 使用方法

在入口文件添加：

```jsx
if ("serviceWorker" in navigator) {
  navigator.serviceWorker.ready.then((registration) => {
    // 监听 SW 更新
    registration.addEventListener("updatefound", () => {
      const newWorker = registration.installing;
      newWorker.addEventListener("statechange", () => {
        // 新 Service Worker 安装完成
        if (newWorker.state === "installed" && navigator.serviceWorker.controller) {
          if (confirm("检测到新版本，是否立即刷新？")) {
            window.location.reload();
          }
        }
      });
    });
  });
}
```

1. `index.html` 禁用缓存（保证入口文件最新）

## 部署注意事项

1. **Nginx 配置禁止 HTML 缓存**（避免服务器缓存 HTML）
    
    nginx
    
    ```jsx
    location ~ /index\.html$ {
        add_header Cache-Control "no-cache, no-store";
        expires -1;
    }
    ```
    
2. 版本检查请求必须**带时间戳**，避免缓存
3. 强制刷新使用 `location.reload(true)`，强制从服务器拉取资源

---

## 总结

1. **简单项目**：直接用方案一（HTML 禁用缓存）
2. **工程化项目**：默认用方案二（哈希文件名）+ 方案三（版本校验）
3. **PWA 项目**：用方案四（Service Worker 主动更新）
4. 所有方案**无需后端配合**，纯前端实现，部署即生效
